> **Prerequisites:** A paid GitHub Copilot plan, a Jira Cloud account with Jira enabled for AI, and Rovo activated for your organization. Both the Jira and GitHub applications must be installed and authorized; users need write access to the target GitHub repository to trigger the agent. Check your Atlassian plan and entitlement rather than assuming a separate Rovo purchase is always required.
